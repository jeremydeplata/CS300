**1. What was the problem you were solving in the projects for this course?**

**2. How did you approach the problem? Consider why data structures are important to understand.**

After looking at all of these I came to the decision of using a Binary Search Tree because I could output the courses in order. There are many data structures you can choose from, it just depends on what you want to do.

**3. How did you overcome any roadblocks you encountered while going through the activities or project?**

I had difficulty with the program compiling. After fixing my errors and allowing it to read the CSV I got it to work. Testing each of the menu items also allowed me to see if my program was doing what I wanted it to do.

**4. How has your work on this project expanded your approach to designing software and developing programs?**

One thing I learned was that it is good to plan out your program. By having the pseudocode ready I had more of an idea on what to do with my second project. It helped me piece my program together.

**5. How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?**

I began organizing my code better by breaking things up into different functions. It made it easier to troubleshoot and edit certain parts of my code. I tried to name my variables appropriately without using too many comments.
